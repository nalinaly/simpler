# CSA L3 宏观瓶颈与直接准入实验

日期：2026-10-29。完整 Device 低于 1.5ms 的目标仍未达成。
当前应优先处理任务交接与 Mix 连续 block 周转，而非根据 L4 的插桩跨度估算收益。
跨类型协同后继直接保留候选的实验未证明稳定收益，生产代码和候选策略测试均已撤回。

## 宏观数据

基线为 `fbce27395`，原生 AICore 二进制为 `20f84347…`。
保持原样 CSA：54 个 kernel、79 个有 kernel 的逻辑 task、2308 个物理执行身份、七项 golden，
Torch 2.12、固定输入与编排。三份新 L3 的 kernel 窗口分别为
1962.332、1932.117、1916.255us，全员无业务 kernel 区间分别合计
549.901、528.767、537.251us，占约 27%–28%。

以下采用窗口居中的 L3-b，五段互不重叠且覆盖完整 kernel 窗口：

| 区间 | 总跨度 us | 全员无 kernel us |
| ---- | --------- | ---------------- |
| 前处理至 t23 首块 | 252.047 | 102.262 |
| t23 大投影 | 388.905 | 8.818 |
| t23 结束至 t56 结束 | 711.527 | 296.296 |
| t56 结束至 16 路 pack 结束 | 328.964 | 61.225 |
| 最终投影及后处理 | 250.674 | 60.166 |

同二进制独立 L1 的窗口为 1886.745us，全员空窗仍有 522.420us。
这些窗口不包含完整启动和退出，不能替代约 2.0ms 的完整 Device 指标。
全员无 kernel 也不等于 Scalar 全部无事可做，可能仍有完成确认、依赖推进和资源协调。

共享开销工具未穿透无 kernel 的 Dummy 14/27 依赖，本次不引用其约 69.8% 调度占比。
离线分析递归折叠中间无执行节点，检查传递前驱先于后继；没有修改运行时依赖图。
逻辑 task 跨度仍包含块间调度，不作为纯计算下界。

## 关键调度链路

L3-b 的典型全员空窗可进一步拆为以下连续区间，单位为 us：

| 前驱至后继 | 末 kernel 至 Resolve | Resolve | Resolve 结束至首块准备 | 首块准备至 kernel |
| ---------- | -------------------- | ------- | ---------------------- | ----------------- |
| t22 至 t23 | 4.524 | 2.642 | 14.975 | 3.366 |
| t23 至 t24 | 5.805 | 3.136 | 11.055 | 4.092 |
| t31 至 t32 | 1.877 | 4.147 | 15.585 | 3.850 |
| t45 至 t46 | 2.158 | 3.819 | 14.968 | 4.119 |

后继启动前的长等待不能全归给 Resolve。准入、成员推进与组启动需要作为完整链路审视。
扇出前缀可能在 Resolve 结束前发布，不能把所有转换强行套成互不重叠的串行四段。

t23 的 512 个 Mix block 分到 32 个 cluster，每个有效核执行 15–17 次，分配较均衡。
组内 kernel 包络中位约 6.85us，同 cluster 的组间间隔中位约 16.99us，启动周期约 23.89us。
最后完成 cluster 的跨度恰为 1.953us 首块偏移、121.673us kernel 包络、265.279us 组间间隔。
该任务全局空窗只有 8.818us，因为不同 cluster 的等待错开；仅看全员 idle 会漏掉这个大头。
L1 的同类组间间隔中位仍为 15.5765us。

t56 后 16 路输出投影拥有共同的数据前驱，但首块启动分散在 198.734us 内。
pack 自身跨度中位 3.9765us，父投影返回至 pack 首块中位 129.333us。
这些等待大量重叠，不能相加为可省时间；最后投影返回至全部 pack 完成只有 67.547us。
N=8 Mix 的成员集合仍为 96 个 worker，N=4 Vector pack 仍为 64 个 AIV。
成员推进不是全体同步启动，也不是全局完成屏障，本实验不改变这套成员合同。

t105 的最后完成 cluster 中，kernel 包络 161.293us，组间间隔 19.186us，首块偏移 7.476us。
其约 188us 跨度主要来自业务执行，不作为固定 kernel 条件下的首要优化对象。

## 直接准入候选

协同后继已满足依赖时，resolver 若有一个空闲持久候选槽，可直接保留该后继，
不再要求后继执行类型与 resolver 相同；随后仍经原 discovery 分类、准入和 block 领取。
普通 N=1 跨类型后继仍入 Ready 队列，候选额度耗尽也回退入队。
保留唯一所有权、完整依赖检查、两份候选额度、错误门禁、成员集合和三 lane Mix 协议。
准入发起者可以是 AIV，但 Mix block 的协调者仍是其固定 C，不把准入等同于执行许可。

代码复用原 `scheduler_task_requires_admission` 判定，增加标量参数入口，避免把 GM 引用
绑定到 Local Memory 参数；首版原生编译地址空间错误及修正日志均保留。
一项旧测试的“必须入队”断言改成“私有候选唯一持有、准入后执行”，
原有等待最后组、inactive C 协调、完成计数及两次物理执行检查不删除。

原生记录确认机制实际生效：基线 26 个 Mix 全由 AIC 准入；候选 20 个由 AIC、6 个由 AIV 准入。
因此不能将后面的无明显收益解释为分支未命中。

## 实测结论与验证边界

同卡 A/B/A 串行采样，每批三轮七项 golden、5 次预热、100 个正式样本：

| 批次 | 原始标签 | 完整 Device 中位数 us |
| ---- | -------- | --------------------- |
| A1 基线 | `idle-direct-admission-before-a` | 2008.468 |
| B 候选 | `idle-direct-admission-after-a` | 2003.344 |
| A2 恢复基线 | `idle-direct-admission-before-b` | 2000.424 |

候选位于两个基线之间，差异小于基线漂移，不支持保留收益的结论。
候选 L3 窗口 1921.006us、全员空窗 539.090us，也在三次基线范围内。
其中中段空窗 305.219us，输出分支跨度 332.037us，未体现对大头的明确改善。
不把一次 L3 的窗口差值或局部正向变化当作完整 Device 收益。

验证范围如下：

- 新增 576 项定向测试，基线 228 项新直传策略断言失败、348 项保护通过；候选全部通过。
  覆盖六个 worker 位置、纯 C/V 与四种 Mix mask、N=1/2/5、sync_start、额度耗尽、
  未完成第二前驱及 Resolve 后错误门禁。初版额外包含不受支持的纯 mask=4，
  该夹具错误已排除，不将其 96 个失败算作生产缺陷或策略 RED。
- 21 个相关 C++ 目标、3574 项 Python 检查通过；A5 和 A5sim 编译通过。
- 严格原生 CSA L4 通过：2308 个执行身份、133 条依赖、46733 个协议事件、96 个 worker，
  两轮七项 golden。L3 另验七项 golden、逐 block 身份及无丢失记录。
- 未运行本候选完整 HBG 设备回归或故障矩阵；不扩大上述验证范围。
- 三批计时及相关捕获的 54 个业务 kernel 指纹相同；未观察到其他 A5 CLI 重叠。
  正式计时没有并行编译、测试或设备查询，但 CLI 监测不等于全系统独占证明。

候选代码与策略测试已撤回，原生三件套恢复至基线；A5sim 也重新构建。
恢复后 21 个 C++ 目标通过。此 A/B/A 只用于候选筛选，不是 1.5ms 目标的五批最终验收。
