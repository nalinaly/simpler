# CSA Mix 完成计数聚合：未见收益，撤回

日期：2026-10-29。完整 Device 低于 1.5ms 的目标仍未达成。
本实验没有缩小合法竞争者、预选 cluster 或更改三 lane 资源合同。
原生生产实现恢复至 `20f84347…`；只保留与计数策略无关的多分波正确性保护。

## 为什么检查完成计数

[L3 宏观分析](2026-10-csa-l3-direct-admission.md)显示，t23 的 512 个 Mix block 中，
每个 cluster 通常执行约 16 组，同 cluster 组间间隔中位约 17us。
原实现每组在三 lane 全部 RELEASED 后，都执行一次全局 `completed_blocks` 原子加一，
由最后贡献者发布 TaskDone 并推进依赖。

本次假设：把多组完成先在协调 C 本地累积，可减少同地址的全局原子更新与 barrier。
这只改变完成数量的汇总时机，领取者、领取顺序和实际执行不变。
减少原子次数不等于减少同样比例的 Device 时间，需要实际检验是否落在关键路径。

## 候选实现及边界

只对普通 N>1 Mix 聚合，N=1 与 sync_start 保持原逐组贡献。
每组仍需三 lane 的释放 ACK、正确 generation、完整输出与 trace 可见性，才能本地加一。
重复 retire 由原 phase 状态机阻止，不再次计数。

领取耗尽、协调者本地槽全部空闲后，检查 epoch、错误、耗尽 cursor 和未发布的 close seal，
一次原子贡献本 cluster 的全部已完成数量。合计达到 N 才触发唯一 TaskDone；
贡献完成后才能发布本 cluster 的关闭 seal、清除本地计数并进入后续任务。
已有成员不需要等待所有其他 cluster 关闭，也没有增加全任务完成屏障。

首版把完成处理重复展开到多个调用点，使无记录循环体积增大。
第二版合并 TaskDone 调用点后进行正式初筛；两版都保留源码、二进制和 L1 捕获。
首版没有正式性能采样，不能把第二版数据归给首版。

该算法改变了逐 block 全局贡献票据的含义。现有 v5 L4 证明尚不支持批量贡献，
若保留算法，必须增加真实批量原子区间、数量与块归属的证明，不能伪造每块原子票据。
本次先做无插桩收益筛选；因没有收益而撤回，没有将不完整的原生证明当作验收通过。

## 实测与宏观核对

同卡串行 B/A，每批三轮七项 golden、5 次预热和 100 个正式完整 Device 样本：

| 批次 | 完整 Device 中位数 us |
| ---- | --------------------- |
| 第二版候选 | 2029.265 |
| 恢复基线 | 2000.475 |

这对样本中候选约慢 1.44%，没有支持保留的收益。
这只是初筛，不是多批稳定负收益证明，更不是 1.5ms 的最终五批验收。
两批与候选捕获的 54 个业务 kernel 指纹相同；未观察到其他 A5 CLI 重叠。
正式采样没有并行编译、测试或设备查询，CLI 检测仍不等于全系统独占证明。

候选 L3 kernel 窗口 2001.710us，全员无 kernel 区间合计 593.070us。
t23 跨度 394.520us，同 cluster 组间间隔中位 17.311us；
中段任务交接空窗合计 333.085us，输出分支展开跨度 352.797us。
与先前三份同基线 L3 相比，没有出现大头收缩，不能只凭减少原子操作数宣称加速。
L3 与完整 Device 是不同捕获与计时范围，不把两者差值精确解释为某项记录开销。

利用既有 L3 的 Dispatch、Complete 与 kernel 身份，逐条拆分 t23 的 480 次同 cluster 组交接：

| 连续区间 | 基线 L3-b 中位数 us | 候选中位数 us |
| -------- | ------------------- | ------------- |
| 上一组末 kernel 返回至最后一次 Complete 开始 | 0.4485 | 0.3120 |
| 最后一次 Complete 开始至所有 Complete 记录结束 | 0.5250 | 0.4480 |
| 所有 Complete 记录结束至下一组首次 payload 准备 | 12.4125 | 12.9285 |
| 首次 payload 准备至下一组首 kernel | 3.5755 | 3.5830 |

三份基线中，第三段中位数分别为 12.221、12.4125、12.176us，候选没有缩短这一大段。
这不是单一 helper 的实测时长：Complete 结束点在 trace 写回和 lane release 之前，
剩余区间还包含 ACK 轮询、退役、领取、descriptor 发布与新组到达。
这是同 cluster 的组间计算空窗，不是所有 cluster 同时 idle。
每条交接的四段精确相加等于该条间隔；不同分量的中位数不要求相加等于间隔中位数。

## 测试范围与保留的保护

候选策略测试 120 项在基线 RED、候选通过；另 20 项既有形状端到端测试通过。
覆盖四种 Mix mask、N=3/17/65、1/2/4 个 cluster、首尾协调者先执行，
检查局部贡献不会提前释放后继、每个 cluster 至多一次全局计数变化，以及四类故障门禁。
策略断言已随候选归档，不保留在生产测试中。

首版的完整 C++ 检查中，21 个目标有 20 个通过；Mix 目标共 481 项中 461 通过、20 失败。
失败对应仍要求逐 block 立即更新全局计数、直接 retire 返回 TASK_LAST 或直接 close 的旧断言。
第二版只复跑并通过上述 140 项定向与形状测试，未重跑完整 C++ 集合。
没有删除或放宽这些既有断言；不将任一候选称为完整测试通过。
A5/A5sim 编译、两轮七项 golden 的 L1，以及独立 L3 的执行身份、依赖和无丢失记录检查通过。
未运行候选严格 L4、完整 HBG 设备回归或故障矩阵，也未声称候选通过 Python 全量检查。

恢复原生产实现后，新增 120 项通用回归保护，复用上述多分波拓扑，但不规定计数必须聚合：

- 每个 block／子任务恰好一次，所有父任务返回、准确完成计数和 TaskDone 先于唯一后继入口。
- 重复 retire 不增加计数，所有成员能够关闭，最终 resolved_task_count 恰为两个 task。
- TIMEOUT、陈旧 epoch、cursor 越界或异常 seal 后，不再增加贡献、发布 TaskDone 或释放后继。

这些通用保护与原有断言一起在基线通过，恢复后的 21 个 C++ 目标全部通过，A5sim 重新构建。
它们是后续优化的正确性护栏，不是本次性能收益。
